# Zaraz Engine Lite 🚀

**Zaraz Engine Lite** es la versión hiper-optimizada y minimizada del majestuoso *Zaraz Engine*. 
Diseñado para la creación rápida y eficiente de videojuegos 2D ligeros, simuladores, RPGs y juegos para dispositivos con menos recursos (¡Como comparar una GameBoy con una Play 4!).

## 🎯 ¿Qué es Zaraz Lite?
Mientras que la versión *Pro* (`zaraz-core`) se centra en simulaciones masivas geopolíticas a nivel mundial, **Zaraz Lite** abstrae las mejores herramientas del motor principal para ofrecer un entorno ágil:
- Motor Geográfico simplificado (Tilesets o Nodos espaciales básicos en lugar de polígonos ultra-detallados).
- ECS (Entity Component System) nativo y ligero.
- Resolutor de colisiones 2D básico y QuadTree súper rápido.
- Cero dependencias pesadas.
- Soporte total de exportación WebAssembly (Juega en el navegador).

## 🧩 Ecosistema Compartido
Al ser el hermano menor, Zaraz Lite hereda la filosofía matemática del `Zaraz Engine`:
- **`market_lite`**: Sistema de trueque y economía sin la complejidad macroeconómica.
- **`tactics_lite`**: Posicionamiento en grid simplificado.
- **`genetics_lite`**: Sistema de traits y herencia básicos para pequeños RPGs.
